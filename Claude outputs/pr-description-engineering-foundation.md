## Які практики Agentic Engineering застосовано

- **Специфікації наперед (SDD, OpenSpec):** зміна `openspec/changes/setup-engineering-foundation/` — proposal, design, 12 вимог із 33 сценаріями (`quality-gates`, `deployment`), 27 задач, кожна з критерієм перевірки. Кожна вимога посилається на рядок PRD (`docs/requirements.md`: NFR-DX-01/02/03, TC-PURE-01, TC-RUNTIME-01, TC-STACK-05, TC-DEPLOY-01).
- **Maker ≠ checker:** перед імплементацією агент зробив окреме рев'ю пропозиції проти PRD і роадмапу (3 критичні, 6 середніх зауважень). Виправлено: вимоги без рядка в PRD додано до PRD, прибрано зайве (coverage), додано сценарії збоїв. Тепер кожну зміну незалежно перевіряє CI.
- **Верифікація замість «здається, працює»:**
  - `npm run verify` = lint → typecheck → unit-тести (Vitest) → Fallow (мертвий код, залежності, цикли) → build, з зупинкою на першій помилці.
  - CI (GitHub Actions) запускає ту саму команду на кожен PR: **зелений, крок verify — 14 с** (бюджет 60 с).
  - Червоні шляхи доведено навмисними поломками (див. нижче), а CI двічі реально впав на розсинхроні lockfile, саме як вимагає сценарій.
- **Контекст-інженерія:** `AGENTS.md` (команди, «definition of done», правила), `DESIGN.md`, правило TC-PURE-01 у лінтері (`lib/` без React/Next/DOM), Claude Code hook запускає Fallow після кожного редагування.
- **Цикли:** агент працював у циклі «задача → зміна → перевірка → позначка в tasks.md» через OpenSpec apply. Знахідки під час імплементації поверталися в design.md (`next typegen` для чистого checkout, Node 22 → 24, lockfile npm 11.21).
- **Інструменти:** Claude Code (desktop + хмарний агент), OpenSpec CLI, Fallow, Vitest, GitHub Actions, CodeRabbit.
- **Що вирішувала я, що агент:** я обирала обсяг (одна зміна-фундамент, потім `weather-core`), Node 24, як обробити два невикористані експорти (виняток у `.fallowrc.json` з причиною), і відклала Vercel до появи застосунку. Агент писав специфікації, код, тести, перевірки й діагностував збої CI.

### Докази верифікації
| Поломка (тимчасова, відкочена) | Де зупинився `verify` |
| --- | --- |
| `var` у `lib/cx.ts` | lint (`no-var`) |
| `const x: number = "nope"` | typecheck (TS2322, файл і рядок) |
| невикористаний `export` у `lib/` | health (Fallow: `lib/cx.ts :5 notUsedAnywhere`) |
| невикористана devDependency (`left-pad`) | health |
| однакові функції у двох файлах | health проходить (дублювання — лише порадчо) |
| `useState` у Server Component | build |
| хибний assert у тесті | test (назва файлу й тесту в логах) |
| `import "react"` / `import("react")` / `require("react")` / `window` у `lib/` | lint, помилка `TC-PURE-01: …` |
